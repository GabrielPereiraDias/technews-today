## 🚀 Sobre o projeto

O **TechNews Today** é uma página de notícias voltada ao universo da tecnologia. O conteúdo reúne uma notícia em destaque sobre inteligência artificial, um vídeo relacionado ao mundo tech e uma área de inscrição para newsletter.

O projeto combina HTML semântico e CSS para criar uma interface organizada, com destaque visual para as informações e adaptação para diferentes tamanhos de tela.

## ✨ Recursos da página

- 📰 **Notícia em destaque:** título, data e resumo sobre inteligência artificial no desenvolvimento de software.
- 📖 **Leitura expansível:** conteúdo adicional exibido com as tags `<details>` e `<summary>`.
- 📺 **Vídeo incorporado:** vídeo do YouTube integrado à página.
- 📧 **Newsletter:** formulário com campo de e-mail, seleção de área de interesse e confirmação dos termos.
- 🎨 **Estilo visual moderno:** tema escuro, gradientes, bordas arredondadas e efeitos de interação.
- 📱 **Layout responsivo:** CSS Grid e media queries para reorganizar os elementos em telas maiores.
- 🧩 **HTML semântico:** uso de elementos como `header`, `main`, `article`, `section`, `footer` e `time`.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação no projeto |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Cores, gradientes, espaçamentos, efeitos e responsividade |
| YouTube Embed | Incorporação de vídeo na página |

## 🎯 Conceitos trabalhados

O desenvolvimento do TechNews Today envolve a construção de uma página web com estrutura semântica, estilização por classes CSS, organização de conteúdo com Grid, incorporação de mídia e criação de formulário com campos obrigatórios.
