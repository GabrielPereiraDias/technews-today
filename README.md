## 🚀 Sobre o projeto

O **TechNews Today** é uma página de notícias voltada ao universo da tecnologia. A proposta é apresentar conteúdos de forma organizada e agradável, reunindo uma notícia em destaque, conteúdo em vídeo e uma área para inscrição em uma newsletter.

O projeto foi desenvolvido para praticar a estruturação de páginas com HTML semântico e a criação de interfaces com CSS, incluindo efeitos visuais, organização em Grid e adaptação para diferentes tamanhos de tela.

## ✨ Funcionalidades e elementos

- 📰 **Notícia em destaque:** título, data e resumo sobre inteligência artificial no desenvolvimento de software.
- 📖 **Leitura expansível:** seção “Leia mais” feita com as tags `<details>` e `<summary>`.
- 📺 **Vídeo incorporado:** área com vídeo do YouTube relacionado à tecnologia.
- 📧 **Formulário de newsletter:** campo de e-mail, seleção de área de interesse e confirmação dos termos.
- 🎨 **Identidade visual:** tema escuro, gradientes, bordas suaves e efeitos ao passar o mouse.
- 📱 **Layout responsivo:** uso de CSS Grid e media query para reorganizar o conteúdo em telas maiores.
- ♿ **Estrutura semântica:** uso de elementos como `header`, `main`, `article`, `section`, `footer` e `time`.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura do portal, conteúdo e formulário |
| CSS3 | Estilização, cores, gradientes, efeitos e responsividade |
| YouTube Embed | Exibição de vídeo dentro da página |

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta `Tech-news`.
3. Abra o arquivo `desafio10a.html` no navegador.

Se estiver usando o Visual Studio Code, você também pode abrir a pasta do projeto e executar o HTML com a extensão **Live Server**.

## 📩 Sobre o formulário

O formulário está montado visualmente e utiliza validações básicas do próprio HTML, como o preenchimento obrigatório do e-mail e a aceitação dos termos. Para realizar inscrições de verdade, é necessário implementar o processamento no servidor indicado em `subscribe.php), que não está incluído nos arquivos atuais do projeto.

## 🎯 Objetivo de aprendizagem

Este projeto reúne conceitos fundamentais de desenvolvimento front-end: organização semântica do HTML, aplicação de estilos com CSS, criação de componentes visuais, incorporação de mídia e adaptação de layout com CSS Grid e media queries.
